# Athena v0.4 plan

## Context
v0.3.0 brought the user's original list (prod fixes, editor breadth, UX, git, perf) to VS Code–like coverage. A gap audit against VS Code/JetBrains (docs/ROADMAP-REPORT.md backlog + the v0.4 research pass) shows the remaining daily-use gaps for a solo Go/TS developer who lives in Claude Code: editing ergonomics (indent/outdent, auto-pairs, line ops), navigation (problems panel, symbols, terminal file:line links), LSP edits (code actions, rename), and reviewing Claude's changes (diff viewer, Claude Code IDE integration). Scope is sized to one wave: three lanes, file-disjoint.

Decision policy (unchanged): VS Code defaults; reversible; no new deps unless MIT/Apache and replacing ≥ 200 lines; keep Claude Code hook/MCP contracts stable.

## Lane x4-edit — editing ergonomics (athena-editor buffer.rs/view.rs/element.rs)
1. Tab / Shift-Tab indent/outdent of selected lines (today Tab replaces a selection with whitespace — bug); `cmd-]` / `cmd-[` too.
2. Auto-closing pairs `() [] {} "" '' ``` ` with type-over, surround selection, backspace deletes an empty pair; skip inside strings/comments using tree-sitter token at cursor.
3. Line ops: move line up/down `alt-up/alt-down`, copy line up/down `shift-alt-up/down`, delete line `cmd-shift-k`, insert line below/above `cmd-enter`/`cmd-shift-enter` (check conflicts with existing bindings first).
4. Find/replace in file: replace field in the editor find bar (`cmd-alt-f`), Replace / Replace All, one undo step.
5. Indentation guides + render whitespace in selection (subtle, theme tokens).
6. Status bar row: Ln/Col (UTF-16 col like VS Code shows chars — use char column), selection count, language, indentation (Tabs/Spaces: N), EOL, encoding UTF-8, LSP state dot, git branch; click language/indent → palette commands. (Shell-level row — coordinate: lane owns a new shell/status_bar.rs + one line in shell.rs render.)
7. Font zoom `cmd-=` / `cmd--` / `cmd-0` for editor + terminal (persisted in Workspace.ui), image viewer keeps its own when focused.
Verify: unit tests for each buffer op (multi-line, mixed indent, unicode), keystroke parsing tests; screenshots if unlocked.

## Lane x4-nav — navigation & LSP edits (athena-lsp, shell/lsp.rs, palette.rs, drawer.rs, athena-term links.rs)
1. Terminal `file:line[:col]` links: detect paths (absolute, relative to the pane cwd, `./`, `a/b.go:12:5`, `file.ts(12,5)`, Go test output `  file_test.go:42:`), Cmd+hover underline, Cmd+click → open_file + go to position. Resolve relative to the shell's cwd (daemon reports cwd via foreground info — check) or project root.
2. Problems drawer tab: all diagnostics grouped by file with severity icons, counts in tab label, click → jump; F8 / Shift-F8 next/prev diagnostic in the active editor; title-bar error/warning counter.
3. Document symbols palette (`cmd-shift-o`, `@` prefix in palette) + workspace symbols (`cmd-alt-o` or `#` prefix; `cmd-t` is taken by New terminal).
4. WorkspaceEdit applier (open buffers via shared buffer = one undo step per file; closed files atomic write) + `workspace/applyEdit` request handler.
5. Rename symbol `f2` (inline input at cursor, prepareRename when supported).
6. Code actions: lightbulb in gutter on lines with diagnostics/available actions, `cmd-.` menu (reuse ContextMenu), apply edits/commands (`workspace/executeCommand`), organize imports on save for Go (gopls `source.organizeImports`) folded into format-on-save.
7. Go to implementation `cmd-f12`, type definition (menu only).
Verify: gopls integration tests for rename/codeAction/documentSymbol/workspaceSymbol; link-detection unit tests with real compiler outputs (go build, go test, tsc, eslint, cargo).

## Lane x4-review — reviewing changes (new diff item, git_view.rs, claude_hooks.rs, mcp.rs)
1. Diff viewer `ItemKind::Diff { path, base: Head|Index }`: side-by-side read-only with synchronized scroll, syntax highlighting, intra-line word diff, hunk navigation (`alt-f5`/`shift-alt-f5`), "Revert hunk"/"Stage hunk" buttons; inline mode toggle. Use `git diff --no-color -U3` + `similar`-free hand-rolled Myers on lines (or adopt `similar` crate (Apache-2.0/MIT) if it replaces ≥ 200 lines).
2. Changes tab row click opens the diff (not the file); "Open File" secondary action.
3. Commit UI in the Changes tab: message box (`cmd-enter` commits), amend toggle, discard changes per file/hunk with confirmation; branch switcher palette (`git switch`, create branch).
4. Claude edits review: add a PostToolUse hook (Edit/Write/MultiEdit) via existing claude_hooks installer (keep existing hooks stable, append new) → `athena notify --edited <path>` → toast "Claude edited x.go" with "Review diff" action opening the diff vs the version before the session's first edit (snapshot on first edit into data_dir/snapshots/<session>/).
5. Research spike (no ship unless solid): Claude Code IDE protocol (lock file in ~/.claude/ide/, WebSocket MCP with openDiff/getCurrentSelection) — document findings in docs/plans/claude-ide.md with a go/no-go.
Verify: diff algorithm unit tests (insert/delete/replace, CRLF, unicode, large file perf), git integration tests for stage/revert hunk and commit in a temp repo, hook installer idempotency tests.

## Release
v0.4.0 via the runbook once all three lanes merge green; update README + docs/ROADMAP-REPORT.md (append v0.4 section).
