# Athena v0.7 plan

## Context
v0.6.0 closed the search, settings, test-runner and git-remote gaps. The remaining gaps from the v0.6 audit and the ROADMAP-REPORT known-gaps lists cluster into three themes: deeper git review (quick-diff peek, file history, whole-file blame, a diff view you can copy from), code understanding (outline, call hierarchy, ESLint diagnostics, Markdown inline highlighting), and workbench ergonomics (a terminal in the bottom panel like VS Code, moving files by dragging tree rows, bracket-pair colours, language defaults that beat global settings). Three file-disjoint lanes; same decision policy.

## Lane x7-git
1. Quick-diff peek: clicking a gutter change bar opens an inline peek under that line showing the old text (red) with Revert / Stage / Next / Previous / Close (VS Code "dirty diff" peek); Escape closes.
2. File history: "Open Timeline" for the active file in a drawer tab: `git log --follow --format=...` with author, relative date, subject; click a commit → diff of the file at that commit vs its parent (reuse DiffView with a new DiffBase::Commit { rev }), "Compare with current".
3. Whole-file blame: toggleable blame gutter (author · age per hunk, colour by age) in the editor; hover shows the commit summary; click opens the commit diff.
4. Diff view polish: text selection + Cmd+C in both panes, right-click menu (Copy, Revert/Stage this change, Open File), "Hide unchanged regions" toggle (collapse to 3 lines of context, VS Code default on for large files), multi-line commit message box (Enter newline, Cmd+Enter commit, grows to 6 rows).
5. Compare two files: tree context menu "Select for Compare" / "Compare with Selected" opens a DiffView (DiffBase::Files).
Tests: git log/blame porcelain parsers (renames, merges, non-ASCII authors), peek hunk mapping, hide-unchanged region math, selection copy text across folded regions.

## Lane x7-code
1. Outline panel: a tree-area toggle (Explorer / Outline segmented control at the top of the file tree, like VS Code's Outline view) listing documentSymbol tree for the active editor, follows the cursor, click to jump, filter box.
2. Call hierarchy: `textDocument/prepareCallHierarchy` + incoming/outgoing calls shown in the References drawer tab as an expandable tree (Shift+Alt+H like VS Code).
3. ESLint/Biome: start `vscode-eslint-language-server` or `biome lsp-proxy` when found in the project's node_modules/.bin (never auto-install; never run from untrusted paths outside the project), diagnostics merged into Problems with source labels; code actions (fix-all on save off by default, setting `eslint.fixOnSave`).
4. Language defaults precedence: built-in per-language defaults (Markdown: word_wrap on, trim off; Go: tab indent, format on save) beat global user settings but lose to the user's `"[lang]"` block, exactly like VS Code's language-specific defaults.
5. Markdown inline highlighting via tree-sitter-md's inline grammar (injection into inline nodes: emphasis, strong, code span, links) and a Mermaid (.mmd) line highlighter; fix Rust ALL_CAPS constants by overriding the broken upstream query predicate.
Tests: gopls integration test for call hierarchy; eslint LS discovery rules (path confinement); defaults precedence matrix; markdown inline captures; rust const capture.

## Lane x7-bench
1. Terminal in the bottom panel: a "Terminal" drawer tab (VS Code panel terminal, Ctrl+` toggles the panel focused on the terminal), multiple panel terminals as sub-tabs, persistent through the daemon like other terminals, moving a panel terminal into an editor pane and back.
2. Drag tree rows to move files/folders (drop on a folder; Alt to copy), with a confirmation prompt like VS Code ("Are you sure you want to move…", with "Don't ask again" stored in settings `explorer.confirmDragAndDrop`), open tabs follow the move, git kicked.
3. Bracket pair colorization (VS Code default on): nested bracket depth colours from the theme (3 cycling colours, both themes), driven by the tree when available.
4. Toasts above web previews: when a toast is visible, hide or shrink the native webview region under it (extend sync_previews covering rects to toasts), or move toasts above the webview's frame.
5. Window zoom (VS Code cmd-= zooms the whole UI): keep code font zoom as `editor.font_size`; add `window.zoom_level` (cmd-alt-= / cmd-alt--? check conflicts) scaling all UI text and paddings via a theme scale factor.
Tests: drawer terminal lifecycle + persistence; move-file ops (into own subfolder refused, name clash prompt, open tabs retargeted); bracket depth colouring with strings/comments; toast/webview overlap rects.

## Release
v0.7.0 via the runbook after lanes merge + review + fixes + docs.
