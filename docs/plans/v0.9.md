# Athena v0.9 plan

## Context
v0.8.0 shipped the Claude workspace, worktrees/gh and LSP extras. The v0.8 gap audit's largest remaining item is a debugger (DAP), followed by semantic highlighting, code lens, user snippets, large/non-UTF-8 file handling and a minimap. Three file-disjoint lanes; same decision policy (VS Code defaults; reversible; new deps only MIT/Apache and replacing ≥ 200 lines; stable Claude hook/MCP contracts).

## Lane x9-dap — debugger
1. New `athena-dap` crate: Debug Adapter Protocol client (stdio transport, request/response/event seq handling, timeouts), modelled on athena-lsp's client (single writer thread, process group, reaper).
2. Go via Delve (`dlv dap`, found on the login PATH like gopls; never auto-installed; behind the per-project trust answer since it builds and runs project code): launch the package / debug test at cursor (reuse athena-testing's test detection and run marks: a "Debug" item next to ▶), attach to process later.
3. `.vscode/launch.json` subset (type go, request launch/test, program, args, env, buildFlags, cwd) + an implicit default config; configs read through the trust gate.
4. UI: breakpoint gutter (click left of line numbers; toggle F9; conditional/logpoint via right-click), persisted per project; debug toolbar (continue F5, step over F10, into F11, out shift-F11, restart, stop shift-F5) in the title bar while debugging; drawer tab "Debug" with Call Stack (threads/goroutines), Variables (lazy expansion), Watch, Breakpoints list, Debug Console (evaluate in frame); current line highlight + auto-open file at stop; hover evaluate while paused.
5. MCP tool `debug_state` (read-only: stopped location, stack, top-frame locals, capped) so Claude can help while paused.
Tests: protocol framing/seq tests with a fake adapter script; Delve integration test (skips if dlv missing) that sets a breakpoint in a temp module, hits it, reads a variable, steps, continues to exit.

## Lane x9-lsp — semantic tokens, code lens, snippets
1. Semantic tokens (full + delta) from gopls/tsserver layered over tree-sitter colours (theme mapping for both themes; setting `editor.semanticHighlighting.enabled` default true like VS Code); off for languages without a server.
2. Code lens: `textDocument/codeLens` + resolve (gopls: run/generate tests, references counts where offered; tsserver references/implementations when enabled in settings), rendered as a muted row above the line (reuse merge-conflict actions row drawing), click runs the command (workspace/executeCommand) or opens references.
3. User snippets: `snippets/<lang>.json` + `snippets/global.code-snippets` in the app support folder (VS Code format: prefix, body, description, scope), merged into completion, tab stops via the existing snippet engine; palette "Configure Snippets".
4. Inlay hints on wrapped lines (currently skipped).
Tests: semantic token decoding (delta edits, legend mapping, multibyte), code lens parsing/placement, snippet file parsing incl. VS Code variables subset ($TM_FILENAME, $CURRENT_YEAR, $CLIPBOARD), wrapped-line inlay positions; gopls integration tests for semanticTokens and codeLens.

## Lane x9-files — big and foreign files, minimap
1. Large-file mode: files over 50 MB (today refused) open read-only via a memory-mapped/paged rope view with no syntax/LSP/folding, fast scroll and find; a banner explains; > 2 GB refused.
2. Encodings: detect UTF-16 BOM / UTF-8 BOM / Latin-1 / Shift_JIS etc. (`encoding_rs` + a small detector; MIT/Apache), open and save back in the same encoding (status bar shows it; click → Reopen with Encoding / Save with Encoding), BOM preserved; refuse unknown binary still.
3. Minimap (VS Code default on; setting `editor.minimap.enabled`): right-edge column with scaled colour blocks per token (not text rendering), viewport slider, click/drag to scroll, hides on narrow panes; cheap (render from cached highlight spans, ≤ 1 ms per frame on 10k lines).
Tests: encoding round-trips (UTF-16LE/BE with BOM, Shift_JIS, Latin-1, UTF-8 BOM), large-file paging tests with a sparse 100 MB temp file, minimap geometry and perf budget test.

## Release
v0.9.0 via the runbook after lanes merge + review + fixes + docs (+ a visual QA sweep if the user is idle).
